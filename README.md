# SOC Investigation Portfolio

This repository contains a collection of security investigation case studies completed across various Blue Team training platforms and practical environments.

Each report documents the investigation process from the initial alert to the final assessment using a structured, evidence-based methodology. Rather than focusing solely on the outcome, these case studies explain the reasoning behind each step of the investigation, including alert validation, threat intelligence, log analysis, endpoint investigation, traffic analysis, incident classification and response decisions.

The goal of this repository is to document my learning journey, strengthen my incident investigation skills and build a technical portfolio that reflects practical Security Operations Center (SOC) and Blue Team experience.

## Objectives

- Practice structured SOC investigation methodology
- Improve log analysis and evidence correlation skills
- Analyze web attacks, phishing, malware and endpoint-related incidents
- Develop technical incident documentation
- Build a portfolio of Blue Team investigations

## What You'll Find in This Repository

Each investigation is designed to document not only the outcome of an incident but also the analytical process behind it.

The case studies include:

- Alert validation and triage
- Evidence collection and log correlation
- Threat intelligence enrichment
- Endpoint and network investigation
- Web, email, and malware analysis
- Incident classification and impact assessment
- Investigation findings and analyst notes
- Final conclusions supported by collected evidence

## Disclaimer

The investigations in this repository are based on scenarios from training platforms, laboratory environments, and hands-on cybersecurity exercises.

The reports represent my own analysis, investigation methodology and technical documentation. Their purpose is to demonstrate practical SOC investigation skills and should not be interpreted as official solutions or real-world incident reports.
